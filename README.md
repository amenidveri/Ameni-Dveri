# Ameni — сайт дверей скрытого монтажа

Стек: Next.js + Decap CMS + GitHub + Cloudflare Pages (как договаривались).

## Как это работает

- `content/categories/*.md` — один файл = один квадрат-категория на главной
  (название, картинка, ссылка, порядок, показывать/скрыть).
- `content/settings/header.yml` — тексты и цвета шапки (логотип, цвет фона, номер телефона, ссылки на Viber/Telegram).
- `pages/index.js` при сборке сайта читает эти файлы и строит страницу —
  сетка квадратов подстраивается сама под количество файлов.
- `public/admin/` — панель Decap CMS. После подключения к GitHub-репозиторию
  на неё заходишь по адресу `сайт.ua/admin`, логинишься через GitHub —
  и там уже обычная форма: добавить категорию, поменять фото, изменить
  цвет шапки. Правки сохраняются как коммит в репозиторий, сайт
  пересобирается автоматически на Cloudflare Pages.

## Чтобы добавить новую категорию (например, "Замки")

Через админку: "Категории" → "+ New" → заполнить название/фото/ссылку → Publish.
Ничего в коде трогать не нужно — новый квадрат появится в сетке сам.

## Дальнейшие шаги

1. Создать репозиторий на GitHub, залить эти файлы.
2. В `public/admin/config.yml` заменить `repo: your-org/ameni-site` на реальный.
3. Подключить Decap CMS к GitHub (OAuth) — обычно через Netlify/Cloudflare identity
   или отдельный auth-провайдер.
4. Подключить домен и Cloudflare Pages, как для мебельного сайта.
